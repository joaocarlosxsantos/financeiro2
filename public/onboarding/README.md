# Mídia de onboarding

Os componentes reservam slots para capturas e vídeos didáticos. Os arquivos visuais ainda não foram fornecidos; enquanto não existirem, a interface mostra um fallback textual com a descrição e a legenda.

Antes de publicar uma captura, use dados fictícios, substitua definitivamente qualquer Client ID por um valor de demonstração e cubra todo o Client Secret no próprio arquivo. Não capture senhas bancárias, saldos ou dados pessoais. Vídeos devem ter legendas e transcrição, sem reprodução automática.

Arquivos esperados pelo assistente Pluggy: `02-meu-pluggy.webp`, `03-aplicacoes.webp`, `04-secret.webp`, `06-demo.webp`, `08-colar-validar.webp`, `09-sync.webp` e o vídeo opcional `v2-meu-pluggy.mp4` com legendas/transcrição.
